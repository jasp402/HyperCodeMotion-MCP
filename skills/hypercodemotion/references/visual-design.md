# Art direction and visual fidelity

## Brief extraction

Record: goal, audience, aspect ratio, length, medium, tone, exact script, brand assets, mandatory text/data, intended pace, and what each reference image communicates. Distinguish **provided facts** from creative suggestions.

## Visual system

Create a compact design system before building layers:
- 2–4 semantic colors, strong text/background contrast, purposeful accent.
- Distinct headline, body and micro-label hierarchy; choose fonts available to the final rendering workflow.
- Shared grid, margins, alignments, radii, shadows and icon line weight.
- Consistent visual metaphors; transitions connect related elements.
- A stable focal point; keep secondary decorations subordinate.

For mobile vertical content, design at the actual 1080×1920 canvas and inspect legibility at phone size. Type size and margins follow the screen rule in [composition.md](composition.md): the canvas wins over a requested size, and vertical formats keep a larger top and bottom margin.

## Working from references

Describe precisely what a supplied image contains (layout, colors, hierarchy, visual rhythm, asset relationships). Do not invent or silently download exact logos or photos. If the original image is intended as an asset, confirm the workflow can ingest and reference it. Capture the asset ID or usable reference **actually assigned by Studio**, not a guessed ID.

## Multi-scene design

Preserve shared anchor elements, brand bar, palette and typography between scenes. Use one idea per beat. For product transformations, prefer a continuous visual object across beats, with text and overlays changing around it. Reserve enough stationary time for comprehension.

## Creative review

Check storytelling, consistent lighting/illustration style, alignment, text fitting, visual emphasis, negative space, palette, continuity and final call-to-action accuracy. A text-only Skill can specify these checks but **cannot declare a passing visual review** without observing a rendered preview.
