01 / THE SYSTEM

From a sentence
to a real project.

One connected workflow. Each transition is explicit: describe, validate, package, refine.

01 / PROMPTDescribe it.

Ask Claude for a motion composition or use a prompt prepared by Studio.

02 / VALIDATECheck it.

Validate composition structure, fields and supported capabilities before packaging.

03 / PACKAGEMake it real.

Create a temporary .hcmotion project and receive open and download links.

04 / REFINEOwn the edit.

Open in Studio and change text, colors, layers and timing yourself.

02 / THE .HCMOTION FILE

One file.
The whole motion.

A .hcmotion is the project itself, not a snippet of code. Everything Studio needs to play and edit your animation travels in one compressed, checked file that you upload or open with a click.

01 — EDITABLE
Edit, don't regenerate.

Change text, colors, layers and timing yourself in Studio. Fix one detail without asking the AI to redo the whole design or spending credits on it.

02 — NO PASTING
Nothing to paste.

Open the link or upload the file. No copying long code between windows, no half-copied paste that breaks the project and gets the blame.

03 — COMPLETE
Everything inside.

Scenes, layers, timing, colors, images, HTML scenes and embedded fonts in one compressed project, small even when the animation is big.

04 — VERIFIED
Checked before it opens.

The connector validates it, Studio checks it again and a SHA-256 fingerprint catches files that were cut short or edited by hand. If something is wrong, Studio says why.

05 — READY
Loaded before play.

Studio loads the whole project, assets included, before the timeline can play. No half-loaded previews, no stutter on the first pass.

06 — PORTABLE
Yours to keep.

Links last 24 hours; the file is yours for good. Save it, reopen it from Load project, or save a new version straight from Studio.

03 / MCP TOOLS

Eight tools.
One creative flow.

These are the actual tools exposed by the connector. No invented render engine or AI generation service.

01 — DISCOVER

get_capabilities

Reads supported composition formats, layer types, properties and effect presets, along with the Studio revision used by the catalog.

READ-ONLY · CAPABILITY DISCOVERY
02 — REFERENCE

get_template

Returns the full design of a Studio gallery template (brief, scenes, HTML scene documents and layers) in the format you ask for, so a new video can follow it.

READ-ONLY · DESIGN REFERENCE
03 — INSPECT

validate_json

Checks a composition, design or improvement patch. Returns errors and warnings before you attempt to open it. Validation is not a rendering guarantee.

READ-ONLY · STRUCTURAL CHECKS
04 — DELIVER

create_hcmotion

Validates a finished composition and packages a .hcmotion file. Valid projects receive temporary Open and Download links for the .hcmotion file; invalid projects are rejected.

TEMPORARY STORAGE · 24 H LINKS
05 — COMMUNITY

get_recreation_brief · propose_template · get_proposal_status · publish_template

Turn a public motion video into a Studio gallery template: Claude gets the brief and frames of the original from its link, recreates it in your conversation and submits it. The recreation is rendered with the Studio engine and compared with the original frame by frame until it matches; then it is published in the gallery marked «Community».

05 / TECHNICAL REFERENCE

Built to connect.
Designed to edit.

Details for developers, technical users and anyone who wants to understand exactly what happens to a composition.

JSON-RPC 2.0

Protocol via Streamable HTTP. The MCP endpoint supports POST methods including initialize, ping, tools/list and tools/call.

4 MB

Maximum request body size documented by the server. This is not a video upload endpoint.

24 HOURS

Time-limited project links. Generated files are stored privately and cleaned up after expiry.

Important: GET /mcp returning HTTP 405 is expected. Clients connect through the MCP protocol. This page at / is for people; the API at /mcp is for AI clients.

UNDER THE HOOD

A 48-byte header.
Then your project.

The header says what the file is, how big it should be and what its contents must hash to. Studio checks all of it before reading a single layer, so a damaged file is refused with a clear reason instead of failing halfway.

Opened a file made by a newer HyperCodeMotion? Studio asks you to update instead of guessing.

SCOPE & PRIVACY

Clear boundaries.

This connector does not generate video, audio or images. It validates and packages compositions supplied by an AI client. get_capabilities and validate_json do not store files. create_hcmotion stores a temporary project in private Vercel Blob storage. Anyone who has a valid download link may access that file before expiration. The project file includes composition data and is not encrypted.
